# LAX Store 🚀

متجر رقمي تفاعلي سحابي تم إنشاؤه لسكربت `sample_tool.py` وجاهز للنشر على **Streamlit Community Cloud** برابط `https://lax-store.streamlit.app`.

### خطوات النشر على Streamlit Cloud في دقيقة:
1. ارفع هذا المجلد إلى مستودع جديد على GitHub (New Repository).
2. افتح [share.streamlit.io](https://share.streamlit.io).
3. اختر المستودع والملف الرئيسي `streamlit_app.py`.
4. في خانة Custom Subdomain اكتب: `lax-store` (أو أي اسم تفضله).
5. اضغط **Deploy!** وسيكون موقعك حياً 24/7 على: `https://lax-store.streamlit.app`.
